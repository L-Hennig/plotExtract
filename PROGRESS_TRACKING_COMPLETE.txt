🎯 WHAT IT TRACKS
═══════════════════════════════════════════════════════════════════════════════

FOR EACH EXTRACTION STAGE:
  📊 Confidence Score         (0.0-1.0, automatic calculation)
  ⏱️  Execution Time           (milliseconds)
  📝 Output Size              (character count)
  🎯 Status                   (pending, running, completed, failed, skipped)
  💾 Extracted Facts          (CSV dimensions, labels, patterns)
  ⚠️  Error Messages          (if any)
  📌 Notes & Warnings         (any issues detected)
  ✅ Validation Result        (yes/no/skipped)

OVERALL METRICS:
  💯 Overall Confidence       (average of stage confidences)
  🏁 Status                   (completed, failed, running)
  ✔️  Validation Status        (passed, failed, skipped)
  🔄 Contradictions           (conflicting data between stages)
  ⏱️  Total Execution Time     (end-to-end timing)
  📚 Extracted Facts by Stage (searchable by stage)
  📋 Output Files Generated   (validation details)

🚀 QUICK START
═══════════════════════════════════════════════════════════════════════════════

1. RUN EXTRACTION (automatic tracking)
   $ python plot_extract_v2/runner.py <image> <prompt_name>

   Output:
   ✅ Creates *.mistral.out_tracking (JSON report)
   ✅ Prints progress summary to console

2. VIEW TRACKING REPORT
   $ python plot_extract_v2/track_analyzer.py <tracking_file>

   Shows:
   ├─ Overview (image, status, confidence, validation)
   ├─ Stage breakdown (status, confidence, timing)
   ├─ Extracted facts (data dimensions, labels)
   ├─ Contradictions (if any)
   ├─ Validation results (X, Y, points, trend)
   └─ Confidence analysis (interpretation)

3. EXPORT FOR BATCH ANALYSIS
   $ python plot_extract_v2/track_analyzer.py report.json --csv summary.csv
